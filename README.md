# 🛡️ SpamShield — NLP SMS Spam & Phishing Classification Engine

[![NLP](https://img.shields.io/badge/NLP-TF--IDF%20%2B%20Naive%20Bayes-blue.svg)](https://github.com/sakshirautela/Spam-SMS-Detection)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> **High-accuracy natural language processing system** classifying spam SMS messages and phishing attacks using n-gram TF-IDF vectorization and Multinomial Naive Bayes classifiers with >98% precision.

---

## 📌 Architecture

* **Text Normalization**: Regex URL extraction, stopword filtering, and lowercasing.
* **Precision Optimization**: Eliminates False Positives to ensure legitimate critical communications are never misclassified.
